# DH Gestão

Demonstração de um app de gestão para lava jato: **agenda de lavagens** e **controle de estoque com alerta de reposição**, para usar no celular. Dados de exemplo, sem cadastro nem servidor. Não é um produto validado.

- Capturas de tela: [`docs/capturas/`](docs/capturas)
- Código do app: [`app/`](app) (Vite + React + TypeScript + Tailwind CSS)
- Plano e decisões: [`PLANO.md`](PLANO.md), [`context.md`](context.md)
- Referência visual: [`stitch_dh_gest_o_car_wash/`](stitch_dh_gest_o_car_wash)

```bash
cd app
npm install
npm run dev      # desenvolvimento
npm run check    # tipos, lint, testes, build e testes de tela
```
